# 📊 MusicLens — Power BI Integration Guide

This directory contains **specifications and connection notes** for Power BI Desktop. It is not a published Power BI Service dashboard and is not part of the Vercel deployment.

PostgreSQL is used as the analytical database and data-engineering layer, while the deployed Vite frontend uses precomputed analytics artifacts for a lightweight serverless deployment.

## 🔌 Connecting Power BI to MusicLens

### Option 1: Direct PostgreSQL / Neon Connection (Recommended)

1. Open **Power BI Desktop**.
2. Click **Get Data** → **PostgreSQL database**.
3. Enter your Neon / Supabase / Local connection details:
   - **Server**: `ep-cool-name-123.us-east-2.aws.neon.tech` (from your `.env` `DATABASE_URL`)
   - **Database**: `musiclens` (or `neondb`)
   - **Data Connectivity Mode**: **Import** (recommended for sub-second visual rendering) or **DirectQuery**.
4. Enter credentials (Username & Password) when prompted.
5. In the Navigator, select the analytical views:
   - `v_genre_summary` — Genre distribution, popularity confidence intervals, and acoustic profiles.
   - `v_artist_leaderboard` — Prolific and high-popularity artists (min 3 tracks).
   - `v_genre_audio_profile` — Multi-dimensional audio metrics across 24 subgenres.
   - `v_top_tracks` — Track catalog detail with release years and popularity scores.
   - `v_release_decade_summary` — Historical catalog evolution (1950s–2020s).
6. Click **Load**.

---

### Option 2: Pre-Exported CSV Files (Offline BI Development)

If developing offline or without a live database, import the CSV files generated by `pipeline/07_export_analytics.py`:

```
data/exports/powerbi/
├── pbi_genre_summary.csv        # Macro-genre counts, percentages, and audio averages
├── pbi_subgenre_summary.csv     # Subgenre-level acoustic metrics
├── pbi_artist_leaderboard.csv   # Artist popularity and track volume rankings
├── pbi_popularity_buckets.csv   # Binned popularity distribution (Zero, Low, Medium, High)
└── pbi_decade_summary.csv       # Decade audio evolution metrics
```

In Power BI Desktop: Click **Get Data** → **Text/CSV** → Select each file in `data/exports/powerbi/`.
